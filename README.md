# Pixel Fix Web

Веб-версия чистилки спрайтов: заделка дырок в обводке, сглаживание контура,
чистка цветовой ряби, пикселизация непиксельных ассетов.

Обработка идёт **целиком в браузере** в Web Worker'ах — файлы никуда не
загружаются, серверной части нет вообще. Хостинг раздаёт только статику.

## Разработка

```bash
npm install
npm run dev
```

## Деплой на Vercel

Проект статический, Vercel определит Vite сам (сборка `npm run build`,
каталог `dist`). Любой из двух путей:

**Через CLI:**

```bash
npm i -g vercel
vercel
```

**Через сайт:** запушить папку в репозиторий на GitHub, затем на vercel.com →
Add New → Project → выбрать репозиторий → Deploy. Настройки менять не нужно.

## Как устроено

- `src/lib/pixelfix.ts` — ядро, порт питоновской версии на типизированные
  массивы. Проверено на совпадение с ней бит в бит.
- `src/worker.ts` — обработка одного спрайта вне главного потока.
- `src/pool.ts` — пул воркеров по числу ядер, очередь задач.
- `src/App.tsx` — интерфейс: настройки, превью до/после, галерея, ZIP.
- `src/CompareViewer.tsx` — пара холстов с общим зумом и сдвигом.

Просмотр: колесо — зум к курсору, перетаскивание — сдвиг, двойной клик —
вписать, кнопки «Вписать» и «1:1». Оба холста рисуют один и тот же вид, так
что при увеличении глаз сравнивает одну и ту же область. Вид сохраняется при
смене настроек — можно зазумиться на проблемном крае и крутить ползунки.

Буферы уходят воркеру через transfer, поэтому копирование не тратит память
на больших батчах.

## Отличие от десктопной версии

Алгоритмы одинаковые, кроме построения палитры: в Python её строит Pillow
(median cut), здесь — своя реализация медианного сечения. Цвета могут на
единицы отличаться, форма и силуэт совпадают точно.
